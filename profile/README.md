### Core Repositories

| Repository | Purpose | Website / Package |
| :--- | :--- | :--- |
| [**`kongono/framework`**](https://github.com/kongono/framework) | Pure PHP 8.5+ full-stack framework — zero Symfony runtime deps, persistent-runtime safe (FrankenPHP / RoadRunner), `kongo prove`, 26-tool MCP, LSP 3.17, and built-in AI companions (**Oshie**, **Chie**, **Hantei**). | [kongono.com](https://kongono.com) · [`kongono/framework`](https://packagist.org/packages/kongono/framework) |

| [**`kongono/zokeibi`**](https://github.com/kongono/zokeibi) | **Zokeibi (造形美)** — Zero-npm, strict-CSP, 55-component UI library & pure PHP 8.5 OKLCH CSS compiler. | [zokeibi.com](https://zokeibi.com) · [`kongono/zokeibi`](https://packagist.org/packages/kongono/zokeibi) |

### Quick Start

```bash
composer create-project kongono/app my-app
cd my-app
php vendor/bin/kongo serve
```
